# 9M2PJU - Online Map and Compass

A premium, interactive web application that simulates a real Silva-style orienteering compass overlaid on dynamic maps.

## Features
- **Silva Compass Dial**: Draggable baseplate and rotatable bezel to measure bearings. The needle points to North, and the dial rotates relative to the baseplate.
- **Dynamic Scale Rulers**: Left, right, and top rulers automatically scale as you zoom or pan, adjusting accurately to local Web Mercator latitude scale.
- **Coordinates & HUD**: Real-time GPS coordinate display under the pivot.
- **Solar Position Calculator**: Calculates current solar azimuth, altitude, sunrise, and sunset times for the compass position.
- **Distance & Area Tools**: Geodesic measurement tools to map out routes and calculate spherical area/perimeter.
- **Waypoints Manager**: Bookmark specific coordinates and jump back to them easily.
- **Multiple Map Layers**: CartoDB Voyager/Dark, OpenStreetMap, OpenTopoMap, and Esri Satellite.
- **Themes**: Obsidian (Dark), Cyberpunk (Neon), and Classic Light.

## Hosting on GitHub Pages
1. Go to the repository **Settings**.
2. Select **Pages** on the left sidebar.
3. Set **Branch** to `main` and path to `/ (root)`.
4. Click **Save**. The website will be live in a minute!
